# 仪表剔关盘卡

> 封卡日：2026-11-22。选定后当日禁止改口。

## 缺陷

仪表可订席把已关盘档期也加进去（仪表聚合未过滤关盘态），点开才发现关盘。

## 选定正确性口径：甲路径（唯一，不得与乙路径混用）

**聚合时同事务排除已关盘并写回仪表数；失败则仪表数滚回旧值。**

- 聚合：`slots_svc.aggregate_dashboard`，同事务内 `status<>'关闭'` 过滤。
- 写回：`slots_svc.write_dashboard_stats` 为仪表数唯一写入口，同事务落 `dashboard_stats` 表。
- 失败：事务回滚，`dashboard_stats` 保持旧值（滚回旧值）。
- 乙路径（先写剔关盘影子再原子改仪表数）禁用；不建影子表，两边不得混用。

## 偏离处置

任何写仪表数的调用若偏离本卡（路径非甲，或未剔关盘）：**拒写并记偏**
（`audit_trail.action='记偏'`，`target='仪表剔关盘卡'`，仪表数零改）。

## 并发纪律

关盘（`POST /api/slots/close`）与刷仪表（`GET /api/dashboard`）同占 `slot:<code>` 档锁；
后到只记争用（`contention_log`），业务零写。占位（`POST /api/holds`）同守此档锁纪律。

## 五处同态

| 处 | 同态口径 |
|----|----------|
| 仪表页 | `slots_bookable` 剔关盘 |
| 关盘态 | `slots.status='关闭'` 可见 |
| 可占列表 | 关盘档 `bookable=false` |
| 对账页 | `include_closed=false` 且汇总剔关盘档 |
| 审计页 | `slot_close` / `dashboard_refresh` / 争用 / 记偏 留痕可查 |

## 不变量

- 登录（admin / clerk / viewer + 123456）与库路径（`data/app.db`）不变。
- 禁止只前端藏关盘卡；禁止无测直线改文案。
